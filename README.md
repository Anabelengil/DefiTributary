# DefiTributary

Fault-tolerant, self-healing architecture enables auto-scaling and real-time-processing within a decentralized layer of the system.

With DefiTributary, you get a lightweight tool that stays out of your way.

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DefiTributary.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
